# 语言审校与冲突处理

风格审校检查文字的实际作用，不把高频词、固定句型或句长当作作者身份和文本质量的证明。

## 先保护内容

标明直接引语、术语、定义、公式、代码、姓名、书名、文献字段和禁止改动的片段。引语内部不按禁词表改写；引语可疑时核对出处或指出待核查。

比较初稿与改稿的主张、否定范围、因果方向、时间、数值和限定词。表达顺畅不能补偿原意改变。

## 检查这些实际问题

| 项目 | 判断依据 | 修改方式 |
|---|---|---|
| 模糊权威 | 有“研究表明”但找不到对应来源 | 补确切来源，或改为有边界的作者判断 |
| 空洞路标 | 只宣布将要分析，未提供范围或方法信息 | 删除或直接给出内容 |
| 否定式对照 | 对比虚设、重复，或后半句没有证据 | 删除修辞；真实概念辨析可以保留 |
| 句尾伪分析 | “体现、反映、推动”后没有证据链 | 解释证据与结论关系，或删除判断 |
| 宣传与拔高 | “领先、重要、深远”等缺少对象和尺度 | 给出比较条件或具体变化；否则改为有限说明 |
| 抽象堆叠 | 读者找不到指代对象和可观察过程 | 解释术语，补材料或动作，不按词数机械删词 |
| 机械衔接 | 同一开头密集重复，关系仍不清 | 改信息顺序或明确逻辑；必要连接词保留 |
| 结构同构 | 无理由地反复三项、同长度段落、金句结尾 | 按内容调整，真实分类和修辞需要可保留 |
| 聊天残留 | 作品正文出现应答、服务邀约或内部规划 | 移出作品正文；协作中的问答和进度不受此项限制 |

## 按模式调整

学术模式保留规定标题、明确论点、必要转折和专业术语。论文写“本文论证”或交代方法不自动构成空话；用“因此”也不证明推理有效。

一般写作减少模板式串场、空泛升华和假装全面。标题、列表、标点和引用不设统一数量上限；是否必要取决于读者和体裁。

技术讲解保留定义、公式、步骤及真实分类；随笔保留情感、节奏和作者性情；有指定格式的文本保留该格式。

只有用户明确要求禁用某个句式时，才把该句式列入本任务的禁令。记录适用范围；不要扩展到直接引语、代码或未授权修改的片段。无法同时满足原样保留与禁用要求时指出矛盾。

## 完成检查

先检查事实与证据，再检查表达，最后回查原意。全文审校需要看段落之间的关系；局部修改不必重写全文。

报告具体问题和影响，不把“问题数为零”当作事实真实、论证成立或文字没有AI痕迹的保证。可选脚本只提供候选提示；人工或模型复核决定是否修改。
