# 人文写作与学术论证 · 提示词模板库

本模板库精选了 5 大典型任务场景的高质量 Prompt，可直接复制并在后方附加你的材料进行调用。

---

## 1. 论文局部润色（保留辨析与限定）

```markdown
使用 humanities-writing，润色下面的中文人文社科论文片段。
要求：
1. 保留专业术语、直接引语、文献出处、数据及限定词；
2. 严格维持原有的判断强度与因果关系，不擅自加强结论；
3. 不新增未提供的理论、文献或新论点；
4. 直接交付修改后的成文稿件；如有值得作者注意的逻辑或语气建议，在正文之外简要说明。

【待润色片段】：
（在此粘贴你的论文文本）
```

---

## 2. 论证结构与逻辑审阅（纯审阅不改写）

```markdown
使用 humanities-writing，审阅下面文本的论证结构与概念逻辑。
要求：
1. 依据原文位置，逐条指出论点、证据支撑、概念边界和段落承接存在的问题；
2. 检查是否有空泛评价、模糊归因或因果关系脱节；
3. 给出针对性的修改思路与依据；
4. 本次任务仅做审阅与诊断，不改写全文。

【待审阅文本】：
（在此粘贴需要审查的学术文本）
```

---

## 3. 文献分析与综述整理（严守已读边界）

```markdown
使用 humanities-writing，根据我提供的文献材料梳理研究现状与文献脉络。
要求：
1. 提取并对比研究对象、核心问题、研究方法、主要论点与关键论据；
2. 严格基于我实际提供的文本（区分元数据、摘要、节选与全文）；
3. 对材料中未交代的部分保持未知状态，严禁无中生有编造引语、结论或页码；
4. 梳理各学者之间的对话与争鸣关系。

【文献材料】：
（在此粘贴文献摘录、笔记或摘要）
```

## 4. 学术摘要与术语翻译（精准对照）

```markdown
使用 humanities-writing，将下面的中文学术论文摘要翻译为学术英文。
要求：
1. 准确传达研究对象、研究范围、论证发现与结论；
2. 保持原有的判断强度、否定关系与因果链条；
3. 专业术语优先采用学术通用规范（如附件对照表），专有名词注明对照；
4. 如遇多义词或争议译法，在译文下方单独给出候选词及理据说明。

【中文摘要】：
（在此粘贴中文学术摘要）
```

## 5. 随笔与前言创作（保留作者声音与真实经历）

```markdown
使用 humanities-writing，依据我提供的真实生活笔记创作一篇随笔 / 书籍前言。
要求：
1. 保留第一人称视角、具体具象的生活场景与真实情感流动；
2. 不编造虚构经历，不使用说教式陈词滥调，结尾不强行说教或公式化升华；
3. 语言文风请参考我提供的写作样本，保持自然、真诚的语调。

【真实笔记与经历】：
（在此输入你的素材与感想）

【文风参考样本】（可选）：
（在此粘贴你以往满意的写作片段）
```
